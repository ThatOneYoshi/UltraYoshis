# UltraYoshis

Mod Features:
* Replaces Red Skull with Pink Yoshi
* Replaces Blue Skull with Blue Yoshi
* Replaces Soap with Green Yoshi
* Replaces Rockets with Grey Yoshi
* Replaces Torch with Golden Yoshi
* Replaces Books with Green Yoshi

### Models

* [Zebb](https://sketchfab.com/juliustripke) on Sketchfab:
  * [Baby Pink Yoshi](https://sketchfab.com/3d-models/baby-yoshi-00388c640231496eba5845dd310d82c1) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
  
  The Other Colored ones were from the same models but just recolored by me.
